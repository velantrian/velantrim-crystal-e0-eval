# velantrim-crystal-e0-eval

## 🔬 Why this evaluation harness is planned

> 🧪 **A proposed independent evaluation of Crystal — not an implemented or completed test harness.**
>
> **Problem:** Retrieval can produce plausible but unsupported, contradictory or outdated claims. Comparative evaluation needs reproducible controls before claiming improvement.
>
> **Planned example (not executed):** Blindly compare baseline RAG/memory with a Crystal-backed configuration on stale and conflicting evidence.
>
> **Current status:** This repository contains a README and LICENSE only. There is no harness code, test dataset, executed experiment or reported result here.

External evaluation harness for Velantrim Exo-Cortex Crystal. Blind A/B testing of baseline RAG/memory vs the same system enhanced with Crystal, with focus on provenance, trust, unsupported claims, contradictions, stale information, and evidence integrity.
