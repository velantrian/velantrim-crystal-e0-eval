# velantrim-crystal-e0-eval

## 🔬 Why this evaluation harness exists

> 🧪 **A separate place to test whether Crystal improves source-grounded AI memory — without assuming it does.**
>
> **Problem:** Retrieval may produce persuasive but unsupported or outdated claims. Comparisons must distinguish measurable gains from evaluation leakage.
>
> **Example:** Blindly compare baseline RAG/memory with a Crystal-backed configuration on contradictory and stale evidence.
>
> **Scope:** External evaluation infrastructure; the existence of tests is not proof of a positive result.

External evaluation harness for Velantrim Exo-Cortex Crystal. Blind A/B testing of baseline RAG/memory vs the same system enhanced with Crystal, with focus on provenance, trust, unsupported claims, contradictions, stale information, and evidence integrity.
